# ☕  CURSO DE JAVA 2026



🗓️ Ruta 1 (Java base): 11 niveles, 134 temas. Ruta 2: Perfil Backend Senior Java. Base de datos: PostgreSQL.

---

## Requisitos
- JDK 17 o 21 (Java 8 y 11 se estudian como referencia en la Ruta 2)
- Terminal (`javac` y `java`) para los Niveles 1 y 2
- IntelliJ IDEA a partir del Nivel 3 (o VS Code con *Extension Pack for Java*)
- Git
- PostgreSQL (Nivel 8 en adelante)
- Maven o Gradle (Nivel 10 en adelante)

## Instalación y ejecución

```bash
# 1. Clonar el repositorio
git clone <URL_DEL_REPOSITORIO> curso-java-2026
cd curso-java-2026

# 2. Verificar la instalación de Java
java -version
javac -version

# 3. Compilar y ejecutar una lección
javac CJ05_Variables.java
java CJ05_Variables
```

Para la parte de bases de datos (Nivel 8):

```bash
sudo -u postgres psql -c "CREATE DATABASE cursojava;"
```

## Formato de cada lección
Todas las lecciones llevan el prefijo `CJ` + número de tema (por ejemplo `CJ05_Variables.java`) y un encabezado con los datos del autor, el curso y el nombre de la lección.
